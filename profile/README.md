## Get fast, repeatable source code refactoring

[OpenRewrite](https://www.moderne.ai/community) (founded and managed by [Moderne](https://www.moderne.ai/)) is an automated refactoring ecosystem that enables developers to effectively eliminate technical debt within their repositories. It consists of an auto-refactoring engine that runs prepackaged refactoring recipes for common framework migrations, security fixes, and stylistic consistency tasks.

OpenRewrite’s core framework and original language parsers (Java, Kotlin, Groovy, and more) are licensed under Apache 2.0. Some additional language parsers and recipes are provided under the [Moderne Source Available License](https://docs.openrewrite.org/licensing/openrewrite-licensing#faq).

Start with the [quickstart guide](https://docs.openrewrite.org/running-recipes/getting-started) and let OpenRewrite handle the boring parts of software development for you.
