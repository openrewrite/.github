# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, discussions or pull requests.

Instead, report them privately through GitHub, using the **Report a vulnerability** button on the **Security** tab of the affected repository. This keeps the details confidential while we work on a fix, and lets us publish an advisory with you.

Please include as much of the following as you can:

* The affected repository, module and versions
* The type of issue, and its potential impact
* Steps or a minimal example to reproduce it

We'll acknowledge your report, keep you informed of our progress, and credit you in the advisory unless you'd rather stay anonymous.

## Supported versions

We release frequently, and fixes go into the latest release. Please check that your report applies to the [latest versions](https://docs.openrewrite.org/reference/latest-versions-of-every-openrewrite-module) before reporting.
