# Getting help

We have multiple channels where you can ask questions about OpenRewrite:

* [GitHub Discussions](https://github.com/openrewrite/rewrite/discussions)
* [Slack](https://join.slack.com/t/rewriteoss/shared_invite/zt-nj42n3ea-b~62rIHzb3Vo0E1APKCXEA)
* [Discord](https://discord.gg/xk3ZKrhWAb)
* [Stack Overflow](https://stackoverflow.com/questions/tagged/openrewrite)

Please only post your question in a **single channel**, and include the details that help us dive in straight away, as described in [asking questions & reporting issues](https://github.com/openrewrite/.github/blob/main/CONTRIBUTING.md#asking-questions--reporting-issues).

Found a bug or want to request a recipe? Please [open an issue](https://github.com/openrewrite/rewrite/issues/new/choose) in the relevant repository.
